    FAQ

    What makes a good README?

    A clear description, install steps, usage examples, features and contribution/license info.

    Is my project info stored?

    No. Everything stays in this page; nothing is sent or saved.

    How are badges generated?

    They are standard shields.io image links built from your repository URL.

    How do the themes differ?

    Each theme changes structure and tone, from a minimal one-pager to a docs-heavy layout with a table of contents.

    Can I edit the output?

    Yes, copy or download the markdown and edit it in your repo.
