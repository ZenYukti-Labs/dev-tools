FAQ

        

          

            What is Open Graph?
            

              Open Graph is a set of meta tags that controls the title, description and image shown
              when a link is shared on social platforms.
            

          

          

            
              Why use a CORS proxy to fetch URLs?
            
            

              Browsers block cross-origin reads, so we try public proxies (allorigins,
              corsproxy.io). You can always paste the HTML head instead, which stays fully local.
            

          

          

            What is the ideal og:image size?
            

              1200×630 pixels (1.91:1), under 5 MB, in JPG or PNG.
            

          

          

            Is my data sent anywhere?
            

              No. Only the URL fetch goes through a CORS proxy. Pasted HTML and edits never leave
              your browser.
            

          

          

            
              Why does my preview look different on the real platform?
            
            

              Platforms cache scraped data and tweak their layouts. These previews are close
              approximations; use each platform's debugger to refresh the cache.
