    FAQ

    What are UTM parameters?

    UTM tags are query parameters (utm_source, utm_medium, utm_campaign…) that analytics tools read to attribute traffic.

    Which UTM fields are required?

    Source, medium and campaign are the standard three. Term, content and id are optional.

    Should UTMs be lowercase?

    Yes. Analytics tools are case-sensitive, so "Email" and "email" would be split into separate rows. Use lowercase with hyphens.

    Does the QR code need internet?

    No. It is encoded with a built-in generator and drawn on a canvas in your browser.

    Where is my history stored?

    Only in your browser's localStorage. Clear it any time with the Clear button.
