FAQ

How do I format JSON online?

Paste your JSON on the left and press Format. It is re-indented with two spaces.

Is my JSON uploaded?

No. Everything runs in your browser using JSON.parse; there are no network calls.

How are errors reported?

The parser message is shown and the offending line number is highlighted in red in the gutter.

What does Sort keys do?

It alphabetically sorts object keys recursively, useful for diffs and stable output.

When does CSV conversion work?

When the root is an array of objects. Nested values are serialised as JSON strings.
